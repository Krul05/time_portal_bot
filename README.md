# time_portal_bot

Временной портал - telegram-бот для создания и прохождения музейных квестов, в котором пользователи могут создавать интерактивные квесты, а другие пользователи - проходить их и  выставлять им оценки. 
Стек технологий:
- Python
- PostgreSQL для хранения данных
- Docker для удобного деплоя, изолирования проекта и быстрого развёртывания локально
- LLM для семантической проверки ответов.

Название бота в telegram - @time_portal_bot.

# Планы на будущее

- Выбор музеев по их типу.

- Возможность добавления изображений к вопросам.
